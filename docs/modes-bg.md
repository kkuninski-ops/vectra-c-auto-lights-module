# Спецификация на режимите

## Основно правило

Модулът работи само когато копчето за фаровете е на `AUTO`.

При ръчни позиции `0`, `габарити`, `къси`, `мъгли` модулът трябва да оставя заводската инсталация да работи нормално.

## Режими

| Режим | Условие | Светлини | Забележка |
|---|---|---|---|
| Welcome | отключване без ключ | конфигурируемо: изключено / габарити / къси / мъгли / комбинация | По подразбиране само по тъмно |
| IGN/ACC | контакт без двигател | конфигурируемо: изключено / габарити / къси / мъгли / комбинация | По подразбиране без ксенон |
| DRL | двигател работи | ксенон + предни/задни габарити | Чрез емулация на ръчни `къси` |
| Goodbye | двигател спира | конфигурируемо | По подразбиране само по тъмно |

## Защо не OP-COM DRL v3

При ръчни `къси` или `габарити` dimmer врътката управлява заедно таблото и CD30/GID.

При AUTO/DRL v3 CD30/GID остава силно осветен. Това значи, че DRL режимът не активира същото night/dimming състояние като ръчно включени светлини.

Затова в AUTO режим модулът трябва да емулира ръчни `къси`, не да разчита на DRL v3.

## Level test

При тъмно палене трябва да се вижда заводският xenon level test.

Логика:

1. Контакт включен, двигател не работи: ксенонът не се включва.
2. Двигателят запалва.
3. Модулът разпознава engine-running.
4. Модулът включва/емулира ръчни `къси` с минимално забавяне.

## Препоръчителна OP-COM база

Да се провери практически:

- `DRL disabled`
- позиция `0`: не свети
- позиция `AUTO`: не свети сама
- ръчни `габарити` и `къси`: работят нормално и dimming-ът е нормален

Ако това се потвърди, външният модул може да управлява AUTO логиката чисто, без да се бори със заводските DRL варианти.
